用 GitHub Gist 把数据存在云端，你和另一个人打开同一个网址就能一起记 Nice 的罐罐。免费、免实名。怎么弄见下面「怎么弄？」。
未启用
① 拿一个 Token
打开 github.com → 右上角头像 → Settings → 最底 Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)。
只勾 gist 这一项，其他都不勾；Expiration 选 No expiration 或自己定；生成后复制那一串 ghp_...（只显示一次，存好）。

② 建共享 Gist
在本页填好 Token，点「＋ 新建共享 Gist」会自动建好并填好 Gist ID；也可以去 gist.github.com 手动建，文件名必须叫 catcan-data.json，再把 ID 抄过来。

③ 另一个人
把你的 Token 和 Gist ID 发给他，他在同一网页这里同样填好、勾上「启用云端共享」，两人就共通了。

⚠️ 安全：这个 Token 只开了 gist 权限，但仍能读写你名下的所有 gist。只发给一起养猫的人；不用了去上面那个页面把它 Revoke 掉即可。
